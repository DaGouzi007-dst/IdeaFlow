# 项目文档

本目录保存 IdeaFlow 的课程材料和项目文档。

- `meetings/`：实际组会纪要。已整理 2026 年 10 月 29 日第一次组会的会议情况、模块分工和后续事项。
- `templates/`：可重复使用的空白模板，不能作为已完成的组会记录提交。
- [立项报告原件](proposal/IdeaFlow-立项报告.docx)：从已有正式文件原样归档，保留原报告内容和日期。
- [仓库现状与集成待办](coordination/仓库现状与集成待办.md)：第 7 组各分支内容、集成边界与整体打包前置检查。
- [开工方案与接口约定（讨论稿）](开工方案与接口约定-讨论稿.md)：供小组讨论的技术方案、模块边界、本周建议及共同样例。
- [第四模块需求分析](requirements/决策与任务跟踪-需求分析.md)：唐逸飞负责的参与者、用例、领域对象和接口边界，待并入小组报告。
- [第 1 周个人进展](weekly/第1周-唐逸飞-决策与任务跟踪.md)：第四模块的实际进展和待办，不代替全组周志。
- [第 2 周个人进展](weekly/第2周-唐逸飞-决策与任务跟踪.md)：决策历史及其验证。
- [第 3 周个人进展](weekly/第3周-唐逸飞-决策与任务跟踪.md)：任务列表改进和接口核对。
- [第四模块接口对接清单](coordination/ProgressGate-第三周接口对接清单.md)：第三周按实际源码整理的接入准备。
- [第三周验证记录](testing/ProgressGate-第三周验证记录.md)：任务筛选、日期边界、历史切换与浏览器验证。
- [第四模块验证记录](testing/ProgressGate-第一阶段验证记录.md)：自动测试、构建及浏览器基本验证。
- [界面原型说明](../progressgate/design-preview/README.md)：第一阶段保留的静态界面源码，与功能演示的边界。
- 小组完整需求分析、其他成员材料和全组周志仍需收齐。整体打包按组长要求暂缓。

会议纪要需记录参会人员、本周进展、障碍、关键决策及理由、AI 建议的采纳或拒绝依据，以及下周任务。

每个人及时提交自己负责的文档和代码。模板和计划不代表已经完成的工作，未确认内容保留“待确认”。
