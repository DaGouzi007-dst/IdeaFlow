# IdeaFlow 界面原型（第一阶段保留版）

此目录保留截至 2026 年 11 月 1 日选择的 S 标志与统一配色探索源码。它用于讨论页面布局、深浅模式、任务与来源之间的操作，不连接 ProgressGate 后端。

## 查看

可以用浏览器直接打开 `index.html`。也可以从仓库根目录启动静态预览：

```bash
python -m http.server 8780 --bind 127.0.0.1 --directory progressgate/design-preview
```

浏览器访问 `http://127.0.0.1:8780/#tasks`。同时保留概览、对话、想法和任务页面，便于检查跨页面风格；这些页面不代表相应模块已经集成。

## 可体验的内容

- S 方向的标志草绘，产品入口、项目卡片和浏览器标签使用统一图形。
- 深浅模式、侧栏收起与展开。
- 示例任务筛选、任务详情切换和状态更改。
- 关联想法展开、来源对话跳转，以及对话中记录示例想法。
- 搜索示例想法；不是正式的跨会话搜索功能。

## 数据与功能边界

任务和想法是人工编造的示例。状态更改与新增示例想法只在当前页面内存保留，刷新后恢复；深浅模式偏好保存在浏览器本地。

“新建任务”“导入对话”等未实现的入口会显示原型说明，不会写入数据库。需要真实创建、保存决策和任务时，请运行上一级目录说明中的 Vue + FastAPI 独立演示。

S 是唐逸飞当前偏好的个人设计候选，尚不代表全组已确认视觉规范。此处 SVG 是根据草案重新绘制的界面版本，仍可调整比例与细节。

历史探索、生成的大图和本机实验记录仍保留在本地 `outputs/`，没有全部复制到此目录。
